# Data provenance

EarthPulse runs on fixed packaged inputs, including satellite retrievals, an assimilated model field and independently attributed imagery. Related NASA Scientific Visualization Studio frames explain the science. The project has not established a frame-to-granule join for the packaged numeric cases.

## Geographic and temporal interpretation

The Atlas draws independent measured or analysed centers, and selects original cells by exact identities. The retained sampling stride describes the distance between downloaded centers. The app keeps native resolution separately in each adapter. The plotting extent is an orientation viewport, while every point or aggregate retains its own coordinates and data status. Map colors and sound use the same retained values, with display limits listed in the legend. Intervals are UTC and use an exclusive end where applicable. Publication cadence does not make packaged observations live.

The historical dust observations are the model's assimilated estimates, and the texture of any atmospheric sound is designed audio. Atlas temporal mappings reflect the quantities in the table. The terrain imagery and coastlines only locate the measurements. Basemap requests, bounds, source imagery and fingerprints are recorded in the [Atlas map manifest](../web/assets/map/provenance.json).

## Reproducibility

- The Atlas build validates the canonical LF versions of its three CSVs. `science/atlas/extract_imerg.py` uses bounded HTTP byte ranges and checks embedded units and dates. The original MUR [subset query](../science/atlas/mur-sst-url.txt) remains packaged. FIRMS's public recent feed rolls forward, so reproducibility uses the exact retained file. An archive download may produce a differently processed historical version.
- The [GEDI extractor](../science/gedi/extract_sample.py) checks pinned source digests and file contents. The [GEDI provenance manifest](../science/gedi/provenance.json) records both verified V001 files and unverified V002 candidates.
- The [dust archive manifest](../science/decode/manifests/dust-sources.json) retains raw granule hashes, exact start/end, processing metadata and a normalized output ledger. Full raw granules are excluded from deployment. Packaged application JSON stores the derived evidence required for offline use.
- [Data intake](../DATA_REQUEST.md) records optional follow-up requests and procedures. The current browser demo ships with the numeric products listed here.
